# Examples

This folder contains multiple examples. These examples all work with the latest commit, but **may not work with the latest release**

## [Ball Pit](ball-pit/)

A box to spawn balls in at the cursor, the balls are of rigid and soft bodies.

Run it with `cargo run`:
```bash
cargo run -p ball-pit
```

Or play it [here](https://glowydeveloper.github.io/Vyxen/examples/ball-pit.html)

## [Counter](counter/)

A text that counts how many time you've clicked.

Run it with `cargo run`:
```bash
cargo run -p counter
```

Or play it [here](https://glowydeveloper.github.io/Vyxen/examples/counter.html)

## [Readme](readme/)

A movable block that was also shown in the [readme](../README.md#a-playable-example).

Run it with `cargo run`:
```bash
cargo run -p readme
```

Or play it [here](https://glowydeveloper.github.io/Vyxen/examples/index.html)
