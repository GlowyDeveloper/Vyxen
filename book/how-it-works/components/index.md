# Components

Components are how you add behavior and data to a `Node`.

Nodes are generic. Behavior comes from `Components` and `Scripts`.

Currently implemented `Components` are:
 - [Collider](./collider.html)
 - [RigidBody](./rigidbody.html)
 - [SoftBody](./softbody.html)
 - [Sprite](./sprite.html)
 - [UiElement](./uielement.html)
