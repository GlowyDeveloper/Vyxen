# Examples

This folder contains multiple examples. These examples all work with the latest commit, but **may not work with the latest release**

## Ball Pit

A box to spawn balls in at the cursor, the balls are of rigid and soft bodies.

View the [source code](https://github.com/GlowyDeveloper/Vyxen/tree/master/examples/ball-pit)

Run it with `cargo run`:
```bash
cargo run -p ball-pit
```

Or, you can also play it [here](./ball_pit.html)

## Counter

A text that counts how many time you've clicked.

View the [source code](https://github.com/GlowyDeveloper/Vyxen/tree/master/examples/counter)

Run it with `cargo run`:
```bash
cargo run -p counter
```

Or, you can also play it [here](./counter.html)
